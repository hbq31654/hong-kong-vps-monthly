## 同价位怎么比才不吃亏

配置表是最容易骗人的东西。同样标 1 核 1GB，实际买到的东西可能差一倍以上。

**流量口径。** LightLayer 香港 $5 档有 10Mbps 不限、500GB/20Mbps、1TB/月 三种写法。Nethub 的 Plan 1 只给 50GB/月，DMIT 当年的入门款给到 2TB/月。50GB 和 2TB 差 40 倍，价格却可能在同一区间。判断方法很朴素：算你每天要跑多少。个人博客一天几百 MB 到 2GB，500GB/月 相当于日均 16GB，够用；做图床、视频中转、镜像站，10Mbps 不限流量反而更稳，因为它不会在某天突然停你的网。

**线路类型。** LightLayer 在洛杉矶把同配置拆成 Global / Standard / Premium 三档，1 核 1GB / 50GB 分别约 $4、$5.60、$7 以上，硬件完全一样，差价全在网络路径上。香港这边标「优化」的档位走的是针对大陆优化的线路，Premium 档明确写 CN2/CMIN2。这条规律值得记住：同一个商家同一种配置，价差通常来自路由，不来自 CPU。

**虚拟化方式。** KVM 能自定义内核、能跑 Docker、能装任意模块；LXD 这类容器方案隔离性弱一些，自定义内核和部分 Docker 场景要先问客服。eServer 的 Business Plus 明确标了 KVM，LightLayer 与 DMIT 的产品页没有把虚拟化类型摆在显眼位置，需要装特殊内核的话，下单前问一句最省事。

## 哪些人其实用不上高配

香港这几个入门档的内存和流量都是按「够用」给的，多数人的实际消耗到不了需要升级的程度。

- **静态站、Hugo/Hexo 生成的博客**：1 核 1GB 绰绰有余，50GB 硬盘放几千篇文章加图片没问题。这类站甚至不需要数据库。
- **Typecho、Z-Blog 这类轻量 CMS**：1 核 1GB 能跑，后台操作会有一点等待感，前台访问不受影响。
- **WordPress 单站**：1GB 内存跑 Nginx + PHP + MySQL 已经很紧，装几个插件就开始吃 swap。想后台流畅，2 核 2GB 是更实际的选择。
- **Telegram Bot、签到脚本、定时任务**：1 核 1GB 跑十几个 Bot 没压力，这类负载几乎不吃 CPU。
- **小型 API、反代、Webhook 中转**：起步用 1 核 1GB，看并发再决定要不要升。
- **多站点托管、带数据库的业务、跨境中转**：直接上 2 核 2GB 起，1GB 内存在这种场景下会天天告警。

判断标准就一条：你有没有一个会持续吃内存的进程。MySQL、Redis、Java、Docker 里跑两三个容器，这四样占一样，1GB 就不够。全都只是 Nginx 加 PHP-FPM，1GB 能撑很久。

月付的价值在于用最小成本把这台机器的脾气摸清。这一个月别只 ping 一下就完事。

**1. 晚高峰丢包，19:00–23:00。** 白天 ping 好看不代表晚上好看。用 `smokeping` 或 `pingpe` 连续跑七天，重点看晚上这段的丢包率和抖动，掉 5% 以上就会影响 SSH 和 API 调用。

**2. 三网回程路由，分运营商测。** 用 `besttrace` 或 `nexttrace` 分别从电信、联通、移动环境测回程，看有没有绕日本、绕美国。只测一条线没用。DMIT 当年公布过一组香港非优化线路的延迟数据：162 个节点平均 220.2ms，其中电信平均 277.5ms、联通 156.5ms、移动 83.6ms，最快节点 11.2ms，最慢 494.8ms。同一台机器，不同运营商能差出三倍，平均值这个数字本身没有参考价值。

**3. 流媒体与 AI 服务解锁。** 用 `region` 脚本或 `unlock-test` 跑一遍 Netflix、Disney+、ChatGPT、TikTok。香港 IP 看港区 Netflix 通常没问题，ChatGPT 这类服务看的是 IP 干净度，要单独验。

**1 个 IPv4 够不够？**
建站、跑 Bot、做 API 都够。需要多个独立 IP 的场景（多站点分离、邮件服务）要确认是否支持加购，以及加购价格。

**10Mbps 不限流量和 500GB/20Mbps 怎么选？**
长期低带宽、流量平稳的用途（Bot、监控、小博客、反代）选不限流量，不用担心月底断网；有突发下载、视频、文件中转需求选 20Mbps 限量，峰值快一倍多。

**香港和洛杉矶怎么选？**
面向大陆用户，香港延迟低一个量级；洛杉矶 $4 起更便宜，但延迟高，适合面向海外或对延迟不敏感的用途。同一商家两地的差价，买的还是那段网络路径。
